# Solario Local documentation

## Access

After installation, start Solario Local and open it through Home Assistant ingress. The direct TCP port is disabled by default.

## First setup

Complete the first account setup only from the protected Home Assistant ingress interface. Keep access and recovery credentials in a safe place.

## Configuration

Solario can automatically discover exact Home Assistant energy metrics. Optional entity fields are available for manual overrides when needed.

## Updates

Home Assistant will offer a new version when this repository publishes a newer app version and matching container image.

## Security

Do not expose the optional direct application port to untrusted networks. Report suspected security issues privately rather than posting credentials, tokens, or exploit details in public issues.
