# Solario Local

Solario Local connects Home Assistant energy data with the Solario local dashboard and optional Solario cloud services.

## Installation

This app is distributed as a pre-built multi-architecture container image. Direct port access is disabled by default; use Home Assistant ingress from the sidebar.

The app supports `amd64` and `aarch64` Home Assistant systems.
