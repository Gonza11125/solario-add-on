# Solario for Home Assistant

Public installation repository for the Solario Home Assistant app.

The application source code is maintained privately. This repository contains only the metadata and documentation needed for installation through Home Assistant.

## Installation

Add this repository to the Home Assistant app/add-on store:

`https://github.com/Gonza11125/solario-add-on`

Then install **Solario Local**.

The protected Home Assistant ingress is enabled by default. After the first administrator setup, optional direct LAN access can be enabled by assigning a host port to `3000/tcp` in the Solario Local Network settings.

Do not forward the direct LAN port to the public internet.
